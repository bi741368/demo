# Gia Nguyen Craft — HTML/CSS demo

## Chạy trên Windows
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt, hoặc mở thư mục trong VS Code.
3. Khuyến nghị dùng extension **Live Server** trong VS Code rồi chọn **Open with Live Server**.

## File
- `index.html`: cấu trúc trang chủ.
- `style.css`: giao diện responsive cho desktop, tablet và mobile.
- `script.js`: menu mobile, tìm kiếm sản phẩm, lọc danh mục và form liên hệ qua email.

## Lưu ý
Đây là bản dựng lại giao diện tham khảo, không phải mã nguồn gốc của gianguyencraft.com. Hình ảnh mẫu tải từ Unsplash và có thể không trùng ảnh sản phẩm thật. Dữ liệu, mã sản phẩm và form cần được cập nhật theo nội dung bạn có quyền sử dụng. Form hiện mở ứng dụng email của người dùng; nó chưa lưu dữ liệu vào máy chủ.
